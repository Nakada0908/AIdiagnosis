# フタバ研究所【AI診断ノベルゲーム】 - ソースコード

AIがあなたのことを診断してくれます。
タイプに分ける診断では分類分けしかできない。
占いでは人の意思が介入してしまう。
では……AIに診断してもらうのはどうだろうか。
コールドリーディングでも、分類でもない。君だけを診断してくれる。
